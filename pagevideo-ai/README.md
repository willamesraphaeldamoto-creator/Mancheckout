# PageVideo AI

Módulo do Mancheckout para hospedar vídeos e criar páginas de vendas com IA.

Recursos: upload para Firebase Storage, URL pública do vídeo, URL de player/incorporação e geração de HTML com OpenRouter.

Configure o Firebase Storage e publique as regras do arquivo firebase-storage.rules. A chave OpenRouter é informada pelo usuário e fica no navegador; nunca coloque a chave diretamente no código público.

URL prevista: https://willamesraphaeldamoto-creator.github.io/Mancheckout/pagevideo-ai/
